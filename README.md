# kkl-agol-tools

כלים בדפדפן לעבודה מול ArcGIS Online (ללא שרת, מתפרסמים ב-GitHub Pages).

## ייצוא ביטויי Arcade
`index.html`: מתחברים לכל ארגון (כתובת + שם משתמש + סיסמה, או טוקן), בוחרים מפות / דשבורדים / ExB,
ומורידים zip עם קובץ `.arcade` לכל ביטוי (פופאפ, תווית, חישוב טופס, רנדרר, Data Expression) + JSON גיבוי.

## אבטחה
- אין בקוד סיסמאות, טוקנים או Client ID. הסיסמה נשלחת רק לפורטל שנבחר, הטוקן בזיכרון הדף בלבד.
- הנתונים נשארים בדפדפן. אין שמירה בשרת. נשמרות רק כתובות פורטל (localStorage).
- טוקנים שמוטמעים בכתובות בתוך ה-JSON נמחקים מהקבצים המיוצאים.

## פרסום
דחיפה ל-`main` מפרסמת אוטומטית (Settings → Pages → Source: GitHub Actions).

## בדיקות
`npm test`
